## Project Overview

Job Harmony is a Tinder-style job matching platform that connects job seekers with employers based on qualifications, not appearances. No pictures, no names initially - just resumes and job requirements.

### Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React, Redux, React Router |
| Backend | Node.js, Express |
| Database | MongoDB, Mongoose |
| Auth | Passport.js, JWT |
